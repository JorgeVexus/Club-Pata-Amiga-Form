# Changelog — 2026-07-27

## `91baeba` — feat: configurar datos por sucursal wellness

### Cambios

- Se agregó configuración independiente de servicios, beneficio y canales digitales para cada sucursal de un centro Wellness.
- Las sucursales adicionales pueden reutilizar los servicios, el beneficio y las redes de la sucursal principal o capturar información diferente.
- Se exige al menos un canal entre Instagram, Facebook, TikTok o sitio web para la sucursal principal y para cada sucursal que use canales propios.
- Se incorporaron validaciones equivalentes en el widget Webflow, el formulario complementario React y la API.
- Se amplió `wellness_center_locations` con servicios, promoción, redes sociales e indicadores de herencia mediante una migración idempotente.
- El directorio público y las vistas administrativas ahora utilizan la información correspondiente a cada sucursal, con fallback para registros históricos.
- Se añadieron pruebas de regresión y documentación de diseño e implementación.

### Impacto funcional

- Un servicio disponible en una sucursal ya no se atribuye automáticamente a todas las ubicaciones de la misma cadena.
- Los centros pueden conservar rápidamente la información principal cuando realmente aplica, sin volver a capturarla.
- Los miembros ven servicios, beneficios y canales digitales correctos para la ubicación consultada.
- Las sucursales existentes continúan funcionando mediante compatibilidad con los datos de la sucursal principal.
